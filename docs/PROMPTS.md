# 画像生成プロンプト（GPT用）

手順: **① キャラデザ** で全身1枚 → その画像を添付して **② パーツ分割**。
切り出し後、PNG名を `assets/player/<パーツ名>.png` にし、`src/data/parts.js` の w/h/pivot 等を実画像に合わせる。

---
## ① キャラデザ（全身・サイドビュー）

```
2Dサイドスクロール・ダークファンタジー・アクションゲーム用の主人公キャラクターを1体、全身で描いてください。

【構図】完全な真横（右向き）、直立の待機ポーズ、全身が収まる。背景は単色の明るいグレー(#d8d8d8)、影・地面・文字なし。
手足の前後が分かれて見えるよう、脚は軽く前後に開き、槍を両手で前方やや斜め上(水平から約20度上)に構える。

【キャラ】小柄で細身の若い女性の槍兵。約6頭身。体にぴったり密着したボディースーツ（首から足先まで）に、顔全体を覆う仮面。
シルエットだけで女性と分かることを最優先にする。
- くびれた腰、はっきりした腰のライン、薄い胸の膨らみ、細い首、丸みのある肩、細く長い脚
- 仮面: なめらかな全面マスク、小さめで顎が細い。口・鼻の凹凸は控えめ。目は細い横スリット1本だけが淡く光る（唯一の色: くすんだ赤 #a8222b）
- 髪は一切見せない（仮面とスーツで完全に覆う）
- 薄く硬質な装甲を最小限だけ（肩の小さな板、肘・膝のプレート、薄い胸当て）。すべて体に密着し、はみ出さない
- 足はスーツと一体の細いブーツ形状
- 【禁止】なびくもの全般: 髪、ポニーテール、リボン、マフラー、マント、スカート、前垂れ、ベルトの余り布、房飾り。体から離れる突起も不可

【槍】真っ黒な槍。全長は身長の約1.4倍、柄は細く真っ直ぐ、穂先は細い笹葉型。布飾りや房は付けない。

【画風】手描き風のフラットな2Dゲームスプライト、セル塗り2〜3階調。全身ほぼ真っ黒(#0b0b0f〜#1a1a22)。
暗い背景でも形が読めるよう、全パーツの輪郭に細い青灰色のリムライト(#8d93a8)。グラデ・テクスチャ・ぼかし多用は禁止。
```

---
## ② パーツ分割（①の画像を添付して使う）

```
添付のキャラクター画像と完全に同じデザイン・塗り・色・リムライトで、2Dリグアニメ用のパーツ素材シートを1枚作ってください。

【共通ルール】
- 背景は透過PNG。不可なら単色の蛍光緑(#00ff00)。影・文字・矢印・枠線・番号は入れない
- 全パーツは同一スケール（元画像と同じ縮尺）。パーツ同士は重ならず、十分な間隔で整列
- 隠れている部分(胴体の後ろ、腕や脚の付け根)も描き足して欠けのない完成形にする
- 関節側の端は丸く太めに、親パーツに隠れる分として約10%長く描き、外側にはみ出さない
- 腕と脚は左右共通で使うので、各1種類だけ描く（奥側は別途加工します）
- 右向き基準。輪郭に細いリムライト(#8d93a8)を残す
- なびく・垂れる要素は存在しないので描かない

【パーツ（全10点）と向き】
1. head 頭：仮面をかぶった頭。直立、右向き。髪なし。目の赤いスリットを残す
2. torso 胴体：直立。首の下〜腰まで。腕は含めない
3. pelvis 腰：腰〜股関節まわり。直立
4. uarm 上腕：肩を上にまっすぐ下へ垂らす
5. farm 前腕：肘を上にまっすぐ下へ垂らす（手首まで）
6. hand 手：槍を軽く握った拳。手首を上に、指は下向き
7. thigh 太もも：股関節を上にまっすぐ下へ
8. shin すね：膝を上にまっすぐ下へ（ブーツ上部まで）
9. foot 足(ブーツ)：右向きで水平。足首が左上
10. spear 槍：全体を水平に、穂先が右。柄の中央付近を握れる直線形状

【縦横比の目安 幅:高さ】head 140:170 / torso 120:290 / pelvis 110:130 / uarm 60:230 / farm 50:220 / hand 60:90 / thigh 90:250 / shin 70:250 / foot 150:80 / spear 1400:40

各パーツに文字ラベルは付けず、配置順は上の番号順（左上→右下）にしてください。
```

**1パーツずつ作り直すとき**
```
添付画像と同じデザイン・画風で、「<パーツ名>」だけを素材として描いてください。背景透過(不可なら#00ff00)、
<向きの指定>、隠れる部分も描き足し、関節側の端は丸く約10%長く、細い青灰色のリムライトを維持。影・文字なし。なびく要素は描かない。
```
> 槍は横長で出力 → 切り出し後に **反時計回り90°回転**（穂先が上）して `spear.png` に。
