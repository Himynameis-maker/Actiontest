# Soulike β — AIに渡すコンテキスト（まずこれを読む）

> 新しいAIセッションには **このファイル + 作業対象のファイル** だけ渡せば足りる。各ソースの先頭コメントにも要約あり。

## 1. 作るもの
横に無限スクロールする2Dソウルライク（beta）。主人公は **小柄な女性の槍兵・全身ほぼ真っ黒**（槍も真っ黒）。
- **地形**: 画面外に出て十分離れた区間はランダムに再生成（見える範囲は絶対に変えない）。
  - 下からすり抜け可能な一段高い足場（**二段ジャンプで届く高さ**）
  - ジャンプで越えられる幅の奈落（**必ず越えられる幅**）
- **戦闘**: パリィ・攻撃は **同時に1つだけ**（アクションは単一ステートマシン。発動中は他アクション不可）。
- 技術: HTML5 Canvas / 素のJS / ビルド無し / GitHub Pages で動く。

## 2. 現状（実装済み）
立ち/走りの **仮ボーン** 付きリグベンチ。パーツ画像(PNG)を `assets/player/` に置くと自動で画像表示に切替（無いパーツは仮ボーン）。
未実装: ジャンプ/物理、地形生成、攻撃/パリィ、敵、HP/スタミナ。

## 3. 起動
`index.html` をダブルクリック（`file://`でも動く。ES module/fetch不使用のため）。公開は GitHub Pages。

## 4. ファイル構成と責務
| ファイル | 責務 | 編集頻度 |
|---|---|---|
| `src/util.js` | 名前空間 `SL`、数学ヘルパ | 低 |
| `src/data/parts.js` | パーツの寸法・ピボット・接続点（画像px） | 画像差替え時 |
| `src/data/tune.js` | 関節オフセット/首バランス/当たり判定/移動/倍率 | **高（エディタから）** |
| `src/data/poses.js` | ポーズ式(stand/run)。新アクションはここに追加 | 中 |
| `src/rig.js` | 階層描画・接地・槍の判定座標 `SL.rig.last` | 低 |
| `src/editor.js` | 数値の自動スライダー化・localStorage保存・コピー出力 | 低 |
| `src/main.js` | ループ/入力/仮背景/HUD。ゲーム本体の入口 | 高 |
| `docs/PROMPTS.md` | 画像生成(GPT)用プロンプト2種 | — |

### 依頼別：渡すファイル
- 首・関節・判定の調整 → `tune.js`（+`rig.js`）
- ポーズ/新アクション追加 → `poses.js` + `tune.js` + `rig.js`
- 画像差替え → `parts.js` + `rig.js`
- 地形/物理/攻撃など新機能 → `main.js` + 関連 `data/*.js`（新規は `src/world/` `src/combat/` `src/player/` に分け、`index.html` にscript追加）

## 5. 規約
- 全コードは `window.SL` 配下。`<script>` 読込順は `index.html` が正（util→data→poses→rig→editor→main）。
- **調整可能な数値はコードに埋めず `src/data/*.js` へ**。エディタは数値/数値配列を再帰的にスライダー化するので、データに足すだけでUIに出る。
- 調整フロー: スライダーで調整（自動保存）→「tune.js/parts.js 用にコピー」→該当ファイルのオブジェクトを丸ごと置換→「保存値を破棄」。※localStorageが残っていると新しい既定値が上書きされる。
- 座標: 右向き基準 +x前 / +y下。角度rad、`+`は垂れた手足が後ろへ・胴は前傾・槍`sp`は前へ倒れる(0=真上)。向きはdir(±1)で`scale(dd,1)`反転。
- リグ: pelvis原点=股関節。腕は `uarm>farm>hand>spear`、脚は `thigh>shin>foot`、`torso>head>hair`。奥側の手足は同じ画像を `farTint` で着色。
- 槍の当たり判定: 握り点→穂先の線分上 `hit.from〜to`、半径`hit.r`。被弾箱は `hurt`（足元中心）。

## 6. ロードマップ
1. 画像差替え（PROMPTS.md）→ pivot調整　2. 移動/ジャンプ/二段ジャンプ/接地　3. チャンク地形（すり抜け足場・奈落・遠方再生成）
4. 攻撃/パリィのステートマシン（フレームデータをdata化、判定はエディタで調整）　5. 敵　6. スカートの別パーツ化、両手持ちIK

## 7. AIへのルール
- 変更は「変更ファイルの全文」で返す。既存の命名・`SL`名前空間・data分離を守る。
- 不明点は質問より先に既存コードの慣習から推定し、仮定は1行で明記。
